Structural Components

Structural components that power Slice.js.

Overview

Structural components power the framework runtime. They are created by Slice.js and exposed under slice.*. You do not build them directly.

Key Components

  • slice.controller for component lifecycle and lookup
  • slice.router for navigation and route rendering
  • slice.translator for translations, locale and formatting (optional to enable)
  • slice.stylesManager for styles and themes
  • slice.events for pub/sub (optional)
  • slice.context for shared state (optional)

When to use which: Context vs Events. All signatures: API Reference.

The Events debug panel (alt+shift+e) shows live subscribers + an emit history; the Context panel shows live state. See DevTools.
