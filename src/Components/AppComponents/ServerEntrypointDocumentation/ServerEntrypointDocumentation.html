Server Entrypoint

api/index.js is your server. It is a normal ES module that the CLI runs for both slice dev and slice start:

createSliceServer() builds an Express app with everything the framework needs — security, compression, the environment endpoint, static assets, bundles, the PWA endpoints — and hands it back without listening and without a catch-all. Nothing is final until you call start().

Adding your own middleware

Anything you add between the factory and start() runs before the SPA fallback, which is the only thing that must be last:

Middleware added after start() never runs. start() mounts the terminal fallback and then listens, so anything registered later is past the piece that answers every page request. Keep await start() as the last line.

start() and the terminal fallback

start({ port, host, signals }):

  • resolves the port as options.port → PORT → sliceConfig.server.port → 3001,
  • mounts sliceFallback() (and the error handler) unless you already mounted one,
  • installs SIGINT/SIGTERM once and closes the server gracefully (signals: false opts out),
  • throws if called twice,
  • returns the http.Server (it is async because the SEO context is prepared before listening).

Where the pieces live
